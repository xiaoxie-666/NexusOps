# DNS 与 TCP 网络连通性排查 Runbook

## 适用症状
服务出现 DNS 解析失败、connection refused、connection timed out、TLS 握手失败或跨服务调用异常。

## 排查顺序（优先只读）
1. 从应用容器和宿主机分别确认 DNS 解析结果、解析耗时和目标地址是否一致。
2. 使用只读连通性检查确认目标 IP/端口的 TCP 建连状态；区分拒绝连接与超时。
3. 检查服务发现、负载均衡健康状态、路由、安全组、防火墙和 NetworkPolicy。
4. 核对证书有效期、SNI、系统时间和 TLS 协议协商错误。
5. 对比故障前后 DNS、路由、证书、网络策略和服务实例变更。

## 安全边界
不要未经审批修改 DNS 记录、防火墙/安全组规则、路由、证书或网络策略。避免将一次 ping 失败直接等同于 TCP 服务不可用。

## 恢复验证
确认域名解析稳定、目标端口可连通、TLS 握手成功，并通过业务接口验证端到端调用恢复。
